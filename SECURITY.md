# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | ✅ Yes    |
| < 1.0   | ❌ No     |

## Reporting a Vulnerability

If you discover a security vulnerability, please do NOT open a public issue.

**Contact:** wardengamerofficial@gmail.com

**Expected Response:** Within 48 hours.

**What to include:**
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt and work on a fix. Once resolved, we will publish a security advisory.
